# 扩展交换图语法

设计一个画交换图用的插件.

感觉可能代码形式画交换图比较难以设计的好用.不如直接设计成一个控件.

编辑器应该是一个一定长宽的表格形式.右键可以设置表格大小.每个表格可以写一定长度的东西.然后允许添加从一个格子指向另一个格子的箭头.箭头有一些常见样式(普通映射,包含映射,虚线等等),可以选中箭头编辑箭头上的内容.

我不知道monaco是否允许在编辑器里插入一个自定义控件啊.如果允许的话会很爽啊.不允许的话就只好做额外窗口->特殊格式渲染的分开了.
